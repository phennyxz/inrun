# INRUN — Corre, Cerrado!

Runner procedural 2D isométrico cartoon para o ecossistema COVIL e formato VLG 0.1.

Este repositório hospeda o primeiro jogo experimental do COVIL. O MVP inclui gerador determinístico, três faixas, salto, deslizamento, colecionáveis e arte vetorial de estilo único. Implementação inicial em desenvolvimento na branch `feat/runner-isometrico-mvp`.

Especificação: https://github.com/phennyxz/covil-game-spec
